# `CAD/2D`
## tiny portable CAD in Rust

(c) Dmitry Ponyatov <dponyatov@gmail.com> 2025 MIT

github: https://github.com/ponyatov/CAD

- designed for use on mobile devices
    - tiny screen, touch-friendly interface, custom GUI
    - size & memory optimized for jet start & editing
- Web plugin for use on drawing-related sites
    - WASM-compiled engine
    - MIT license for easy sharing
